# Upgrade v1.35.1 → v1.35.2

**Date**: 2026-02-05

Same procedure as v1.35.1. Additionally removed Cilium after memory pressure on home lab nodes — see `experiments/cilium-migration-attempt.md`.

```bash
apt-mark unhold kubeadm kubelet kubectl
apt-get install -y kubeadm=1.35.2-1.1 kubelet=1.35.2-1.1 kubectl=1.35.2-1.1
apt-mark hold kubeadm kubelet kubectl
kubeadm upgrade apply v1.35.2
systemctl daemon-reload && systemctl restart kubelet
# drain/upgrade/uncordon workers
```
