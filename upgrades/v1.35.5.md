# Upgrade v1.35.4 → v1.35.5

**Date**: 2026-05-12

Routine patch upgrade. Updated containerd to 1.7.28 and kernel to 6.17.0-35-generic on all nodes.

```bash
# Update containerd first
apt-get install -y containerd.io
systemctl restart containerd

apt-mark unhold kubeadm kubelet kubectl
apt-get install -y kubeadm=1.35.5-1.1 kubelet=1.35.5-1.1 kubectl=1.35.5-1.1
apt-mark hold kubeadm kubelet kubectl
kubeadm upgrade apply v1.35.5
systemctl daemon-reload && systemctl restart kubelet
# drain/upgrade/uncordon workers
```
