# Upgrade v1.35.0 → v1.35.1

**Date**: 2026-01-10

## Procedure

```bash
# Update apt repo
apt-get update
apt-cache madison kubeadm | head -5

# Upgrade kubeadm on control plane
apt-mark unhold kubeadm
apt-get install -y kubeadm=1.35.1-1.1
apt-mark hold kubeadm

# Verify upgrade plan
kubeadm upgrade plan v1.35.1

# Apply upgrade
kubeadm upgrade apply v1.35.1

# Upgrade kubelet + kubectl on control plane
apt-mark unhold kubelet kubectl
apt-get install -y kubelet=1.35.1-1.1 kubectl=1.35.1-1.1
apt-mark hold kubelet kubectl
systemctl daemon-reload && systemctl restart kubelet

# Upgrade workers (repeat on k8s1, k8s2)
kubectl drain k8s1 --ignore-daemonsets --delete-emptydir-data
# on k8s1: apt upgrade kubeadm kubelet kubectl, kubeadm upgrade node
kubectl uncordon k8s1
```

## Verify

```bash
kubectl get nodes
# All nodes Ready on v1.35.1
```
